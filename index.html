Algorithm Comparison
Logistic Regression
Linear model that estimates the probability of default using a sigmoid function. Fast, interpretable, good baseline. Best for linearly separable data.
Typical Accuracy~80–83%
K-Nearest Neighbors
Classifies by majority vote among K=7 nearest training samples. Distance-weighted. Non-parametric — no assumptions about data distribution.
Typical Accuracy~85–88%
Decision Tree 🏆
Hierarchical if-else rules (max_depth=12). Highly interpretable. Achieves top accuracy on this dataset due to non-linear decision boundaries it can capture.
Typical Accuracy~90–92%
Naive Bayes
Probabilistic classifier based on Bayes' theorem with feature independence assumption. Very fast, works well with small data. Slightly lower accuracy here.
Typical Accuracy~78–82%
SVM (RBF Kernel)
Finds the optimal hyperplane maximizing margin between classes. RBF kernel maps to higher-dimensional space for non-linear separation. Competitive with Decision Tree.
Typical Accuracy~89–92%

Why Decision Tree Performs Best

🌳
Non-linear BoundariesThe data has complex, non-linear relationships between features and default — Decision Tree captures these with its hierarchical splits.
📊
Mixed Feature TypesThe dataset has categorical (loan_grade, intent) and numeric features. Trees handle both naturally without needing separate encoding pipelines.
⚖️
After BalancingWith oversampling applied, the tree learns both classes equally well, boosting its minority-class recall significantly.
🔑
Feature Importanceloan_percent_income and loan_int_rate are strong splitters — the tree exploits these threshold splits effectively.

Regression Algorithms
Linear Regression
Fits a hyperplane minimizing sum of squared residuals. Simple, fast, interpretable. Struggles with multicollinear features and outliers.
Typical R²~0.83
RMSE~$29K
Ridge Regression 🏆
Linear regression with L2 regularization (α=10). Prevents overfitting from multicollinear features (80+ correlated housing attributes). Best on this dataset.
Typical R²~0.88
RMSE~$24K
SVR (RBF Kernel)
Support Vector Regression with radial basis function kernel. Finds a tube around the regression line and minimizes violations. Robust to outliers in SalePrice.
Typical R²~0.85
RMSE~$27K
Polynomial Regression
Extends linear regression with polynomial feature interactions (degree=2). Captures non-linear effects but risks overfitting on small datasets without regularization.
Typical R²~0.80
RMSE~$32K

Why Ridge Regression Performs Best

🏠
High DimensionalityWith 80+ features (many correlated), Ridge's L2 penalty shrinks redundant coefficients without zeroing them out.
📉
MulticollinearityGrLivArea and 1stFlrSF are correlated; Ridge handles this better than plain Linear Regression which becomes unstable.
🔄
Log TransformApplying log1p to SalePrice normalizes the skewed target — all models benefit but Ridge exploits it best.
⚖️
Balanced Bias-VarianceRidge trades a bit of bias for much lower variance, resulting in better generalization on the validation set.
